7  The two-step approach

The two-step approach uses an effect-informed discovery model to learn about graph uncertainty, then estimates the effect through a separate Bayesian adjustment regression. The motivation is to retain direct control over the effect prior while allowing a decision about which covariates to adjust for. Its output is a specified modular procedure, rather than automatically the posterior of the joint model in Chapter 6.

7.1 Discovery, adjustment and a common prior

In the first step, a proper I-MAP prior and its marginal likelihood produce graph weights \(w_{\mathcal D}(\mathbf X)\). The active-effect marginal is \(h(\tau)\) and structural-null graphs receive their separately specified prior mass. The graph weights define which adjustment sets are possible or credible, but the union of graph-specific valid sets need not be valid across all supported graphs.

For a chosen candidate \(Z\), the second step fits

\[ X_y=\tau X_d+\beta_Z^\top X_Z+e_Z,\qquad e_Z\sim N(0,\sigma_Z^2). \]

When \(Z\) is valid in the causal graph, the treatment coefficient equals \(\tau_{dy}\). Assign the same active-effect prior \(h(\tau)\), along with a proper prior \(q_Z(\beta_Z,\sigma_Z^2\mid\tau)\). The nuisance prior is part of the second-step model; it may change with \(Z\). If null uncertainty is retained, specify a point mass at \(\tau=0\) and its mixing weight as well. A continuous prior alone does not reproduce the structural-null component of graph averaging.

Equality of the marginal effect priors is the intended connection between the steps. A conventional normal/inverse-gamma regression prior usually specifies a normal coefficient prior conditional on \(\sigma_Z^2\), giving a marginal Student distribution after integrating the variance. That marginal must be checked against \(h\); using the same conditional scale or hyperparameter in two different models is insufficient. Independent \(h(\tau)\) and nuisance priors are one possibility, but may sacrifice conjugacy.

Both steps can use the same data if their output is declared to be a modular estimator or decision rule. This does not mean multiplying the first-step effect posterior by a second likelihood for those same observations: such a multiplication counts the observations twice unless justified by a joint model. A cut or other modular posterior needs an explicit definition of which feedback is removed. Splitting the data gives a different procedure; if a first-subset posterior is used as a second-subset prior, it is no longer the original \(h\). Matching priors therefore supplies comparability, not automatic joint Bayesian coherence or post-selection calibration.

7.2 Choosing the adjustment set

The second step needs an action and a loss before an optimal adjustment set is defined. A possible action reports the posterior mean from each candidate regression and uses the first-step graph-and-effect posterior as a reference distribution for loss evaluation. This is a decision rule applied to the data, not an additional likelihood update. The admissible candidate collection can encode adjustment validity, computational cost or substantive restrictions. The O-set supplies a frequentist precision benchmark, while a Bayesian choice depends on the actual loss.

7.3 A well-defined action space

An adjustment regression can be selected by minimizing posterior expected loss. Let \(\tau=\tau_{dy}(\mathcal D,\theta)\) have a proper reference posterior \(p(\mathcal D,\theta\mid\mathbf X)\) with a finite second moment. For each candidate \(Z\), specify a regression prior and obtain a reported number \(a_Z(\mathbf X)\), such as its posterior mean. This action is computable from the data and \(Z\); it cannot depend on an unknown true DAG unless a further, observable rule averages those DAG-specific actions.

“Bayesian OLS” does not by itself specify a posterior. A regression likelihood, prior, and treatment of the residual variance are required. A regression coefficient for an invalid set is an associational estimand, even if it is assigned a Bayesian posterior. The reference posterior for the causal effect and the candidate regression posteriors serve different roles.

7.4 Squared-loss decision rule

Take \(L(Z,\tau)=(a_Z-\tau)^2\). Put \(\mu=E[\tau\mid\mathbf X]\) and \(V=\operatorname{Var}(\tau\mid\mathbf X)\). The exact risk is

\[ R(Z\mid\mathbf X)=(a_Z-\mu)^2+V, \qquad Z^*\in\operatorname*{arg\,min}_Z(a_Z-\mu)^2. \]

NoteProof

Conditional on \(\mathbf X\), \(a_Z\) is fixed and \(E[\tau-\mu\mid\mathbf X]=0\). Expanding the square gives

\[ E[(a_Z-\tau)^2\mid\mathbf X] =(a_Z-\mu)^2-2(a_Z-\mu)E[\tau-\mu\mid\mathbf X]+E[(\tau-\mu)^2\mid\mathbf X] =(a_Z-\mu)^2+V. \]

Since \(V\) does not depend on \(Z\), the minimizers are those of \((a_Z-\mu)^2\).

Analytical result. The chosen action is closest to the Bayesian model averaged effect mean among the available actions. The posterior variance of the reference effect is constant across \(Z\). The regression posterior variance \(s_Z^2\) does not appear. Thus squared loss for the reported point action does not separately penalize the candidate estimator’s variance. The full Bayes risk is not equal to its first term; that term is only an equivalent minimization objective.

With \(\mu_{\mathcal D}=E[\tau\mid\mathcal D,\mathbf X]\) and \(V_{\mathcal D}=\operatorname{Var}(\tau\mid\mathcal D,\mathbf X)\), the law of total variance gives

\[ V=\sum_{\mathcal D}p(\mathcal D\mid\mathbf X)V_{\mathcal D} +\operatorname{Var}_{\mathcal D\mid\mathbf X}(\mu_{\mathcal D}). \]

If one formally writes a DAG-dependent action \(a_{\mathcal D,Z}\), its risk is

\[ \sum_{\mathcal D}p(\mathcal D\mid\mathbf X) \{(a_{\mathcal D,Z}-\mu_{\mathcal D})^2+V_{\mathcal D}\}. \]

The constant term here is the within-DAG variance; the total mixture variance additionally includes between-DAG variation. This expression describes an action that observes \(\mathcal D\); it is not an implementable decision under graph uncertainty without an additional rule. If \(a_{\mathcal D,Z}=a_Z\) for every DAG, minimizing the first term recovers the preceding closest-to-\(\mu\) rule, with the between-DAG constant retained in the full risk.

7.5 Validity, precision, and alternative losses

Proposals. Distinct objectives need distinct specifications. Possible choices include:

  • Restrict to sets valid in every DAG with posterior support, if such sets exist; that intersection can be empty.
  • Require \(P(Z\text{ is valid in }\mathcal D\mid\mathbf X)\ge1-\varepsilon\), documenting the chosen tolerance and the posterior graph model.
  • Use the decision criterion \((a_Z-\mu)^2+\lambda s_Z^2\) with a specified \(\lambda\ge0\) to penalize regression posterior dispersion. This is a new criterion, not a consequence of the original squared-loss rule.
  • Evaluate predictive or repeated-sampling risk with an explicit data-generating model if the goal is estimator bias and sampling variance.

Enumeration of candidates is one computational approach, not a demonstrated necessary or uniquely available algorithm. The union of graph-specific valid sets contains sets invalid in other supported DAGs. A graphical characterization of a Bayesian criterion depends on its particular loss and posterior specification. The frequentist O-set result optimizes a different quantity (Chapter 3).

7.6 Structural null effects and shrinkage estimators

Consider the shrinkage rule \(\tau^{PB}=P(\tau\ne0\mid\mathbf X)\,\tau^B\). Let \(H\) indicate an active effect model, with \(\tau=0\) under \(H=0\). Then

\[ E[\tau\mid\mathbf X]=P(H=1\mid\mathbf X)E[\tau\mid H=1,\mathbf X]. \]

This is a coherent squared-loss estimator if \(\tau^B\) is the conditional active-model posterior mean. If \(\tau^B\) is already the unconditional model averaged mean, multiplying by \(P(H=1\mid\mathbf X)\) applies the inclusion factor twice. If \(\tau^B\) is selected from adjustment regressions, the product needs its own loss-based justification.

Under absolutely continuous priors on original DAG coefficients, a nonzero path-sum polynomial equals zero on a Lebesgue-null set. Therefore, within an ancestor DAG, exact cancellation has prior and posterior probability zero whenever the posterior remains absolutely continuous; DAGs without ancestry supply a point mass at zero. This almost-sure relation does not say every ancestor parameter value has a nonzero effect. If graph sampling is restricted to ancestry, that structural-null uncertainty has already been removed (Chapter 6).

7.7 A four-graph adjustment example

Take treatment 4 and outcome 6. Consider graphs with common edges \(1\to2\), \(1\to4\), \(4\to5\), \(4\to6\) and \(5\to6\), with these additional specifications:

Graph Additional edges O-set for the effect of 4 on 6
\(\mathcal D_1\) \(2\to5\), \(3\to6\) \(\{2,3\}\)
\(\mathcal D_2\) \(2\to5\), \(6\to3\) \(\{2\}\)
\(\mathcal D_3\) \(2\to5\) \(\{2\}\)
\(\mathcal D_4\) \(5\to2\) \(\varnothing\)

The set \(\{1\}\) is valid in every graph, since it blocks any back-door path through the treatment’s only parent. The set \(\{2\}\) is valid in the first three graphs, but in \(\mathcal D_4\) it conditions on a descendant of mediator 5. Likewise, \(\{1,3\}\) is valid in the other graphs but conditions on an outcome descendant in \(\mathcal D_2\). The union of graph-specific valid sets therefore includes inadmissible choices for some supported graphs.

For graph weights \(w_1,\ldots,w_4\), the posterior validity probability of \(\{2\}\) is \(w_1+w_2+w_3\). A rule requiring validity probability at least \(1-\varepsilon\) admits this set only when \(w_4\le\varepsilon\). A rule requiring validity in every supported graph rejects it whenever \(w_4>0\). Neither rule alone specifies the estimation loss, so it must be combined with a stated action criterion. Population regression checks for these examples are given in Section A.5.

7.8 Posterior reports and uncertainty

After a point-action choice \(Z^*(\mathbf X)\), the selected regression posterior is conditional on that regression model and its prior. It need not include uncertainty from learning the graph or selecting \(Z\). An effect posterior obtained by averaging coherent graph models already includes graph uncertainty; a mixture of separate adjustment-regression posteriors needs its own weights and interpretation.

If the action is a distribution rather than a number, squared loss for a point estimate is no longer the appropriate specification. A proper scoring rule or an explicit interval loss can compare posterior reports, with validity and measurement costs added when relevant. Claims of efficiency, coverage or shrinkage improvement must be assessed for that complete procedure. In particular, a variance penalty cannot be inferred from the point-action squared-loss identity.
