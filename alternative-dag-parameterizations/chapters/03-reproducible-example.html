A.2 Mathematical expectation

For independent standard normal observations, the sample mean has expectation zero and standard deviation \(1/\sqrt{n}\). This is a theoretical result; the simulation illustrates its numerical behavior.

A.3 Method and script

The downloadable R script uses seed 20261010, 2,000 repetitions, and sample sizes 10, 100, and 1,000. Run it independently from the repository root:

Rscript scripts/R/001-monte-carlo.R

The book executes that same script when rendered:

Code 
source("scripts/R/001-monte-carlo.R")
Code 
knitr::kable(mc_results, digits = 4)
Code 
plot(mc_results$sample_size, mc_results$empirical_sd,
     log = "xy", pch = 19, xlab = "Sample size", ylab = "Standard deviation")
lines(mc_results$sample_size, mc_results$theoretical_sd, col = "steelblue", lwd = 2)
legend("topright", c("Simulation", "Theory"),
       pch = c(19, NA), lty = c(NA, 1), col = c("black", "steelblue"), bty = "n")

A.4 Interpretation and limitations

Table A.1 and Figure A.1 compare simulated variability with the analytical prediction. Differences reflect finite Monte Carlo sampling. A simulation can provide evidence or a counterexample; it does not replace a general mathematical proof.

This example does not establish any I-MAP finding.

# Reproducible computation: workflow demonstration {#sec-example}

## Question and status

**Status: demonstration.** Can a standalone R script supply the book's table and figure without copying results by hand?

## Mathematical expectation

For independent standard normal observations, the sample mean has expectation zero and standard deviation $1/\sqrt{n}$. This is a theoretical result; the simulation illustrates its numerical behavior.

## Method and script

The downloadable [R script](../scripts/R/001-monte-carlo.R) uses seed `20261010`, 2,000 repetitions, and sample sizes 10, 100, and 1,000. Run it independently from the repository root:

```bash
Rscript scripts/R/001-monte-carlo.R
```

The book executes that same script when rendered:

```{r}
#| label: run-example
source("scripts/R/001-monte-carlo.R")
```

```{r}
#| label: tbl-monte-carlo
#| tbl-cap: "Empirical and theoretical standard deviations of sample means."
knitr::kable(mc_results, digits = 4)
```

```{r}
#| label: fig-monte-carlo
#| fig-cap: "Empirical variability compared with the theoretical prediction."
plot(mc_results$sample_size, mc_results$empirical_sd,
     log = "xy", pch = 19, xlab = "Sample size", ylab = "Standard deviation")
lines(mc_results$sample_size, mc_results$theoretical_sd, col = "steelblue", lwd = 2)
legend("topright", c("Simulation", "Theory"),
       pch = c(19, NA), lty = c(NA, 1), col = c("black", "steelblue"), bty = "n")
```

## Interpretation and limitations

@tbl-monte-carlo and @fig-monte-carlo compare simulated variability with the analytical prediction. Differences reflect finite Monte Carlo sampling. A simulation can provide evidence or a counterexample; it does not replace a general mathematical proof.

This example does not establish any I-MAP finding.
