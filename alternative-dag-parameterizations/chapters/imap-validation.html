A.1 The four-node diamond

Take \(1\to2\), \(1\to3\), \(2\to4\), \(3\to4\), with treatment \(d=1\) and outcome \(y=4\). Write

\[ L^\top=\begin{pmatrix} 1&0&0&0\\a&1&0&0\\b&0&1&0\\0&c&e&1 \end{pmatrix},\qquad D=\operatorname{diag}(v_1,v_2,v_3,v_4). \]

Thus \(a=L_{12}\), \(b=L_{13}\), \(c=L_{24}\), \(e=L_{34}\) and

\[ \tau_{14}=ac+be,\qquad O=\varnothing. \]

The sign follows from \(B=-L\) off the diagonal: each causal path has two edges. Starting from \((1,2,3,4)\), transpose \((3,4)\) and then \((2,4)\) to obtain ordering \((1,4,2,3)\). Put

\[ s_3=v_4+e^2v_3,\qquad s=s_3+c^2v_2,\qquad t=ac+be. \]

Analytical result. The resulting factorization, displayed in original node labels, is

\[ \widetilde L^\top= \begin{pmatrix} 1&0&0&0\\ a-tcv_2/s&1&0&cv_2/s\\ b-be^2v_3/s_3&cev_3/s_3&1&ev_3/s_3\\ -t&0&0&1 \end{pmatrix}, \]

\[ \widetilde D=\operatorname{diag}\left(v_1,\frac{v_2s_3}{s}, \frac{v_3v_4}{s_3},s\right). \]

The last row represents \(X_4=tX_1+\widetilde\epsilon_4\). Both directed paths contribute to the outcome coefficient through \(t=ac+be\). All denominators are positive.

Note

The I-MAP graph has edges \(1\to4\), \(1\to2\), \(4\to2\), \(1\to3\), \(4\to3\), and \(2\to3\). It has six edges, while the original graph has four. Its eight-dimensional ambient parameter space must be constrained to retain the original six-dimensional model. If \(ac+be=0\), the numerical \(1\to4\) coefficient vanishes even though that edge belongs to the graph-defined I-MAP.

A.2 Reverse constraints with arbitrary variances

Start with an unconstrained factorization in \((1,4,2,3)\),

\[ \widetilde L^\top=\begin{pmatrix} 1&0&0&0\\a'&1&0&f\\b'&h&1&g\\c'&0&0&1 \end{pmatrix},\qquad \widetilde D=\operatorname{diag}(w_1,w_2,w_3,w_4),\quad w_j>0. \]

To restore \((1,2,3,4)\), transpose \((4,2)\) then \((4,3)\). Define

\[ s_2=w_2+f^2w_4,\qquad t_4=\frac{w_4w_2}{s_2},\qquad A=\frac{c'w_2+fw_4a'}{s_2}. \]

The two restored coefficients absent from the original diamond are

\[ L^{\mathrm{back}}_{23}=h-\frac{gfw_4}{s_2},\qquad L^{\mathrm{back}}_{14}=\frac{w_3A+gt_4b'}{w_3+g^2t_4}. \]

Therefore the exact constraints are

\[ h(w_2+f^2w_4)-gfw_4=0,\qquad w_3(c'w_2+fw_4a')+gw_4w_2b'=0. \]

These polynomial equations include all positive variance values and do not divide by an edge coefficient. When \(w_2=w_3=w_4=1\), they reduce to

\[ h=\frac{gf}{1+f^2},\qquad c'+a'f+gb'=0. \]

Solving the latter as \(g=-(c'+a'f)/b'\) is valid only on the chart \(b'\ne0\). At \(b'=0\), keep \(c'+a'f=0\) and \(h=gf/(1+f^2)\); excluding that case would discard valid parameter values. Unit transformed variances are a restriction on the example, not a harmless simplification covering every original model. The general formulas above allow arbitrary positive transformed variances.

A.3 Validation methods

A.3.1 Analytical methods

Structural substitution expresses the outcome as a regression on treatment and external parents of the causal nodes. Path polynomials distinguish graphically implied zeros from coefficient cancellations. Adjacent equation operations preserve the covariance matrix, and uniqueness of Gaussian regressions identifies the factorization in each variable ordering. Restoring the original ordering gives an exact missing-edge characterization of the constrained model.

Graphical I-MAPs are defined through the original DAG’s d-separations. Numerical coefficient support agrees with the graph-defined support under faithfulness; individual unfaithful parameter values can have additional zeros. All covariance factorizations assume strictly positive error variances.

A.3.2 Numerical validation

The base-R validation script independently computes d-separation by ancestral moralization and Gaussian factorizations by direct regression. The finite validation domain, coefficient and variance ranges, random seed and numerical tolerance are specified in Appendix A. The same script produces the tables and graph illustration.

The graphical checks concern all DAGs in the specified finite ordered class. Numerical checks compare population covariance factorizations, effect coefficients and reverse constraints. They assess the implementation against analytical benchmarks; they do not establish general theorems or the statistical performance of Bayesian estimators.

A.3.3 Reproduction

Run the validation from the repository root:

Rscript scripts/R/002-imap-validation.R

Standalone execution writes regenerated tables and execution-environment information to results/. The calculations use base R. A full HTML build executes the same validation code:

The seed, inputs, parameter ranges and tolerances define the computational experiment; runtime information supports reproduction across environments.

A.6 A Bayesian evidence and sampling benchmark

The Bayesian benchmark uses the three Markov-equivalent orientations of the path skeleton on \((1,2,3)\). Only the chain \(1\to2\to3\) permits the target effect of 1 on 3. It generates \(n=120\) zero-mean observations from that chain, with \(B_{12}=0.7\), \(B_{23}=0.9\) and all error variances one. The baseline uses compatible DAG-Wishart shapes with \(a=8\), \(U=I_3\) and equal graph masses. Seed is 20261012.

For the chain, the baseline coefficient blocks for \(B_{12}\) and \(B_{23}\) are independent. Therefore its prior and posterior moments of \(\tau_{13}=B_{12}B_{23}\) factor into the corresponding coefficient moments. In a node block, if the coefficient has conditional mean \(\mu\) and conditional variance \(vK^{-1}_{uu}\), with \(v\sim\operatorname{IG}(r,b_0)\), then

\[ E[B^2]=\mu^2+\frac{b_0K^{-1}_{uu}}{r-1},\qquad E[B^3]=\mu^3+\frac{3\mu b_0K^{-1}_{uu}}{r-1}, \]

provided the required absolute moments exist. The benchmark has \(r>2\), which also gives a finite fourth moment. Independence then yields \(E[\tau^k]=E[B_{12}^k]E[B_{23}^k]\) for \(k\le4\).

Apply the properly normalized \(\tau^2\) tilt only to the active chain; keep the two null priors unchanged. Its evidence correction is exactly \(E_0[\tau^2\mid\mathbf X]/E_0[\tau^2]\). Its conditional posterior mean is exactly \(E_0[\tau^3\mid\mathbf X]/E_0[\tau^2\mid\mathbf X]\). These give independent analytical references for the evidence and sampling calculations. This tilt is not an assertion that every DAG has a common Gaussian moment-prior marginal.

A.7 Replicated effect-hypothesis comparison

The introduction’s Figure 1.1 is generated by the main simulation script, calling reusable functions in effect-testing.R. It uses seed 20261013, 200 independent replicated datasets per scenario, and nested sizes \(n=25,50,100,250,500,1000\). The chain and collider have coefficients \(0.8\), unit error variances and known zero means. All 25 labeled three-node DAGs are included, of which nine have a path from 1 to 3. The uniform graph prior is identical in the two analyses, giving active mass \(9/25\). Parameter priors use \(a=8\), \(U=I_3\) and the normalized effect-squared tilt on active graphs; null priors are unchanged.

No estimated graph score or graph MCMC is involved. For a directed path \(p\), let \(T_p\) be its product of structural coefficients. The exact moment is

\[ E_0[\tau_{13}^2]=\sum_{p,r}E_0[T_pT_r]. \]

Node blocks are independent under the DAG-Wishart prior and posterior. Each product \(T_pT_r\) uses at most two coefficients from any node block. For two coefficients entering \(j\), with conditional mean vector \(\mu_j\) in the \(B\) convention,

\[ E[B_{uj}B_{vj}]=\mu_{uj}\mu_{vj} +\frac{b_j}{r_j-1}(K_j^{-1})_{uv},\qquad r_j>1, \]

where \(b_j\) is the inverse-gamma rate, not an edge coefficient. Multiplying the relevant node moments and summing over path pairs includes covariance and cross-path terms. Both prior and posterior second moments are finite with the selected hyperparameters, so Section 6.6 supplies exact evidence corrections.

Code 
knitr::kable(effect_testing_results$summary, digits=5, row.names=FALSE)

The independent moment check uses seed 20261014 and 30,000 direct baseline parameter draws for each of the nine active DAGs, under both prior and posterior. It computes the effect using the separate three-node identity \(\tau_{13}=B_{13}+B_{12}B_{23}\) and compares its sampled square with the path-pair expectation. All 18 discrepancies are within seven estimated Monte Carlo standard errors; the largest standardized discrepancy is 1.95. This checks the moment implementation without using simulated integration to generate the plotted evidence. The earlier three-graph benchmark separately verifies compatible-score equality.

The plotted bands are empirical 10th–90th percentiles across datasets. Monte Carlo errors in this table concern the estimated replicate means; neither quantity is a posterior credible interval. A posterior cutoff would define a testing rule, but the figure alone supplies no general type-I-error or power guarantee. Its behavior depends on the effect size, nuisance parameters, hyperparameters and graph prior. In particular, observationally equivalent chain and fork truths give identical distributions of these outputs, as explained in Section 1.2.

No estimated graph score or graph MCMC is involved. For a directed path $p$, let $T_p$ be its product of structural coefficients. The exact moment is

$$
E_0[\tau_{13}^2]=\sum_{p,r}E_0[T_pT_r].
$$

Node blocks are independent under the DAG-Wishart prior and posterior. Each product $T_pT_r$ uses at most two coefficients from any node block. For two coefficients entering $j$, with conditional mean vector $\mu_j$ in the $B$ convention,

$$
E[B_{uj}B_{vj}]=\mu_{uj}\mu_{vj}
+\frac{b_j}{r_j-1}(K_j^{-1})_{uv},\qquad r_j>1,
$$

where $b_j$ is the inverse-gamma rate, not an edge coefficient. Multiplying the relevant node moments and summing over path pairs includes covariance and cross-path terms. Both prior and posterior second moments are finite with the selected hyperparameters, so @sec-nonlocal-prior supplies exact evidence corrections.

::: {#algo-effect-enumeration .algorithm}

**Input:** Data, treatment/outcome, a finite DAG collection, compatible baseline hyperparameters and fixed graph masses.

**Output:** Exact baseline and normalized-tilt effect-inclusion probabilities, up to floating-point arithmetic.

1. Enumerate DAGs and directed treatment-to-outcome paths; classify graphs as active or structural-null.
2. Compute each baseline evidence and each active graph's prior moment $C_{\mathcal D}=E_0[\tau^2\mid\mathcal D]$.
3. Update the DAG-Wishart blocks with the data. Compute each active graph's posterior second moment using the path-pair expansion.
4. Multiply active evidences by $E_0[\tau^2\mid\mathbf X,\mathcal D]/C_{\mathcal D}$; retain baseline evidences for null graphs.
5. Normalize graph masses times evidences separately for the two priors, sum over active graphs, and obtain null probabilities by complementation.

Exact small-graph effect-hypothesis enumeration.
